## **개요와 목표**

포켓 매니저 에센셜은 Essentials 엔진 위에서 연고 도시를 키우고 팀을 이끌어 9개 지방의 정상에 도전하는 Windows용 포켓몬 육성·경영 팬게임이다.

핵심 재미는 세 가지다.

* **도시가 눈에 보이게 자란다.** 도시 크기와 건물이 맵에 그대로 나타난다.  
* **180개 클럽이 같은 규칙으로 성장한다.** 같은 도시를 나눠 쓰는 클럽끼리 협의, 부지 경쟁, 더비가 생긴다.  
* **중요한 경기는 직접 전투로 치른다.** 자동 진행과 건너뛰기도 고를 수 있다.

기존 포켓 매니저(웹, 안드로이드, Windows)는 그대로 유지하고, 이 게임은 별도 프로젝트로 만든다. 이 문서는 시스템 설계를 고정하기 위한 것이며, 구현 순서는 로드맵 절에 있다.


## **범위**

1차 버전은 도시 경영과 직접 전투의 핵심 순환을 만드는 데 집중하고, 멀티플레이, 다국어, 슈퍼리그, 웹과 모바일은 만들지 않는다.

| 구분 | 항목 |
| :---- | :---- |
| 포함 | 9개 지방 180클럽, 도시·건물·협의·재정·교통, 직접 전투와 자동 진행, 업적, 도감, 원작·새 트레이너 시작, 대회 순환 개최 |
| 제외 | 멀티플레이, 다국어(한국어만 제공), 슈퍼리그, 웹·모바일 |
| 핵심 순환 검증 뒤 추가 | 도시 위기 이벤트, 인접 배치 시너지, 2칸을 쓰는 큰 건물 |


## **확정 사항 요약**

지금까지 합의한 규칙은 아래 12개 영역이며, 각 절에서 세부를 다룬다.

| 영역 | 확정 내용 |
| :---- | :---- |
| 플랫폼 | Windows 전용, Essentials 기반 |
| 시작 | 원작 트레이너 또는 새 트레이너. 새 트레이너는 기존 한 명의 자리를 대신하고, 그 트레이너는 세계에서 사라진다 |
| 경기 | 직접 전투가 기본, 자동 진행과 건너뛰기를 고를 수 있다 |
| 육성 | Essentials의 포켓몬 시스템을 그대로 사용 |
| 도시 | 원작 도시만 사용, 클럽이 있는 도시 100곳, 연고지는 클럽이 공유 |
| 크기와 부지 | 도시 크기 5단계(돈으로 확장, 일반 도시는 4단계까지, 5단계는 수도 전용), 공공 부지와 클럽 부지로 분리 |
| 건물 | 여러 단계로 성장, 도시 크기가 부지 수와 단계 상한을 정함 |
| 리그 도시 | 지방마다 1곳, 5단계 수도로 고정, 리그 관리위원회가 운영, 클럽 4\~5, 메인·사이드 스타디움, 대회 개최 지방은 순환 |
| 인프라 | 공유 도시는 트레이너 협의(월 1회), 단독 도시는 자유롭게 건설 |
| 재정 | 클럽 재정과 도시 공공예산 분리, 한도 있는 대출, 계약형 스폰서 |
| 이동 | 교통 단계가 이동일수와 원정 범위를 정하고, 방문 도시도 내 도시와 같은 템플릿 |
| 제외 | 멀티플레이, 다국어, 슈퍼리그 |


## **시작 방식**

플레이어는 원작 트레이너로 시작하거나, 기존 트레이너 한 명의 자리를 대신하는 새 트레이너로 시작한다. 지금 포켓 매니저와 같은 방식이다.

* **원작 트레이너**: 그 트레이너의 연고 도시, 클럽, 초기 팀, 전문 타입으로 시작한다.  
* **새 트레이너**: 빠진 트레이너는 세계에서 완전히 사라지고, 플레이어가 그 클럽의 자리(팬 점유율, 부지, 경기장 지분)를 이어받는다. 리그와 대진표의 인원은 그대로 유지된다.  
* **전문 타입 규칙**: 관장·사천왕의 전문 타입 규칙을 포켓 매니저에서 그대로 이식하고, 플레이어에게도 똑같이 적용한다.  
* **시작 화면**: 클럽이 있는 도시마다 경쟁 클럽 수를 보여준다. 공유 도시는 규모가 크지만 경쟁이 있고, 단독 도시는 한적하지만 직접 키워야 한다.


## **이전 방식과 새 방식의 비교**

두 게임은 서로를 대체하는 것이 아니라 강점이 다른 별개의 게임이다. 포켓 매니저는 접근성과 속도, 에센셜은 몰입감과 세계감이 강점이다.

| 항목 | 포켓 매니저 | 에센셜 |
| :---- | :---- | :---- |
| 플랫폼 | 웹, 안드로이드, Windows | Windows만 |
| 경기 | 자동 시뮬 중심 | 직접 전투 중심(자동 가능) |
| 성장 | 메뉴의 시설 업그레이드 | 맵에서 보이는 도시 성장 |
| 세계 | 트레이너 180명 중 선택 | 180클럽이 도시를 키우는 세계 |
| 기능 | 멀티, 8개 언어, 슈퍼리그, 업적 225개 | 1차는 축소(멀티·다국어·슈퍼리그 제외) |
| 제작 부담 | 그림 의존도 낮고 패치 주기가 빠름 | 그림과 맵 작업이 큼 |

### **병행 전략**

1. 포켓 매니저는 1.1.x에서 버그 수정과 작은 개선 중심으로 유지한다.  
2. 에센셜은 그림 없이 가능한 시뮬 코어 프로토타입부터 만들어 재미를 검증한다.  
3. 재미가 확인되면 맵과 그림 작업에 들어간다.  
4. 시뮬 코어를 웹(JS)에서 먼저 시험하면 재미가 입증될 경우 포켓 매니저에 도시 모드로 일부 되돌려 넣을 길도 열린다(선택지).
