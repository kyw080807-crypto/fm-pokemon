## **월드맵과 맵 제작 방식**

맵은 세 층으로 나누고, 모든 도시는 같은 템플릿 위에 도시 상태 데이터로 건물을 배치해서 맵 제작량을 줄인다.

| 층 | 내용 |
| :---- | :---- |
| 월드맵 | 9개 지방이 한 장에 보이는 그림 지도. 도시를 누르면 원정 이동이나 정보 화면으로 연결된다 |
| 도시 맵 | 플레이어가 도시를 걷는 타일맵. 공공 부지와 클럽 부지가 있는 같은 템플릿을 모든 도시가 쓴다 |
| 길 | 압축된 짧은 맵 또는 연출 이동. 도보로 다니는 길은 만들지 않는다 |

### **템플릿 \+ 도시 상태**

* 맵에 들어갈 때 스크립트가 도시의 상태(크기, 부지별 건물과 단계)를 읽어 건물 외관을 배치한다. AI 도시도 같은 규칙으로 자라기 때문에 별도 제작 없이 상대의 도시가 눈에 보인다.  
* 도시의 개성은 **지형 배경 8\~10종 \+ 고유 랜드마크 1\~2개**로 만든다(해안, 산악, 사막, 설원, 평야, 숲, 도심, 섬 등).  
* 클럽이 없는 중립 도시도 같은 템플릿을 쓴다.  
* 건물 외관은 종류별 한 벌을 모든 도시가 공유하고, 레벨은 3종(Lv1\~2, Lv3\~4, Lv5)만 구분한다.  
* 시작은 부지 배치를 하나로 고정하고, 필요하면 변형을 나중에 점차 추가한다.

### **확인이 필요한 것**

맵 진입 시 건물을 동적으로 배치하는 방식은 Essentials 스크립트로 가능하다고 보지만 시험으로 확인해야 한다(로드맵 단계 2).
