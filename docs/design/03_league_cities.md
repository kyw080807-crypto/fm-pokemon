## **리그 중심도시와 대회**

지방마다 리그 중심도시가 1곳 있고, 지방의 수도로서 5단계 거대도시로 고정되고, 사천왕과 챔피언 등 4\~5명이 공유한다. 공공 인프라는 리그 관리위원회가 운영한다(게임 시작 시 도시 구성 참고).

| 지방 | 리그 도시 | 클럽 |
| :---- | :---- | :---- |
| 관동 | 석영고원 | 그린, 칸나, 시바, 국화, 독수 |
| 성도 | 금빛시티 | 목호, 일목, 카렌, 꼭두, 아폴로 |
| 호연 | 그랜드시티 | 성호, 혁진, 회연, 미혜, 권수 |
| 신오 | 포켓몬리그(신오) | 난천, 충호, 들국화, 대엽, 오엽 |
| 하나 | 포켓몬리그(하나) | 노간주, 망초, 블래리, 카틀레야, 연무 |
| 칼로스 | 포켓몬리그(칼로스) | 카르네, 파키라, 즈미, 간피, 드라세나 |
| 알로라 | 라나키라마운틴 | 쿠쿠이, 하라, 라이치, 아세로라, 카힐리 |
| 가라르 | 슛시티 | 단델, 금랑, 마리, 비트, 호브 |
| 팔데아 | 포켓몬리그(팔데아) | 테사, 칠리, 뽀삐, 팔자크, 네모 |

* 성도 리그는 원작에서 관동과 석영고원을 공유하지만, 한 도시에 10명이 모이면 너무 많아 성도 최대 도시인 금빛시티를 리그 도시로 삼는다.  
* 리그가 도시가 아닌 지방(신오, 하나, 칼로스, 알로라, 팔데아)은 리그 장소를 도시로 승격해 다룬다.  
* **스타디움**: 메인 스타디움 1개(대회 결승)와 사이드 스타디움 1개(리그 일반 경기). 부지를 쓰지 않는 고정 랜드마크이고, 업그레이드는 리그 관리위원회의 안건이다.  
* **PWT·PET·PENT는 개최 지방을 돌아가며 정하고, 경기는 그 지방 어느 도시의 경기장에서나 열린다(결승은 반드시 수도의 메인 스타디움)**.
