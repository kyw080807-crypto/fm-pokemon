## **게임 시작 시 도시 구성**

현재 포켓 매니저의 새 게임 시작 상태(전력, 명성, 경기장, 시설 단계, 파티의 주 타입)를 그대로 읽어서 100개 도시의 1년차 모습을 정했다. 수치는 현재 게임의 월드 생성을 5번 돌린 평균이다. 같은 규칙을 코드로 옮기면 트레이너 데이터가 바뀌어도 도시가 자동으로 다시 계산된다.

### **원칙**

* 크기는 도시에 사는 클럽의 힘과 원작에서의 도시 규모를 합쳐 정한다. 강한 트레이너가 사는 곳이 크고, 원작의 대도시는 주민이 약해도 일정 크기 이상이다.  
* 리그 도시는 지방의 수도다. 5단계 거대도시로 고정해 시작하고, 5단계는 수도만 가질 수 있다. 일반 도시는 4단계 대도시까지 자랄 수 있고 4단계로 시작하는 도시는 없다.  
* 수도의 공공 인프라는 도시 회의가 아니라 리그 관리위원회가 맡는다.  
* 모든 도시에 빈 공공 부지를 최소 1칸 남긴다. 처음부터 무엇을 지을지 고르는 선택이 있어야 한다.  
* 클럽 건물은 현재 게임의 시설 단계를 옮겨 온다. 관장은 지금처럼 훈련이 강하고, 사천왕·챔피언은 시설이 고르게 높다.

### **계산 규칙**

클럽 힘 \= (명성 \+ 전력 환산) ÷ 2\. 전력 환산은 현재 전력 80\~136을 0\~100으로 바꾼 값이다.

도시 점수 \= 가장 강한 클럽의 힘 \+ 나머지 클럽 힘 합 × 0.35 \+ 원작 규모 보정(마을·타운 0, 시티·도시 \+6, 지방 최대급 도시 \+15).

| 도시 점수 | 시작 크기 | 공공 부지 |
| :---- | :---- | :---- |
| 리그 도시 | 5 거대도시 (수도, 고정) | 12 |
| 80 이상 | 3 중도시 | 8 |
| 55\~79 | 2 소도시 | 6 |
| 55 미만 | 1 마을 | 4 |

지방 최대급 도시(노랑, 금탄, 축복, 구름, 미르, 하우올리, 너클, 테이블)는 점수와 상관없이 최소 3단계로 시작한다. 그래서 위 "도시 크기와 건물" 표의 크기 1 설명을 "시작 상태"에서 "최소 단계"로 고쳤다.

### **클럽 건물 변환**

| 현재 게임 | 새 게임 |
| :---- | :---- |
| 명성 30 미만 / 30\~44 / 45\~59 / 60\~74 / 75 이상 | 클럽하우스 Lv1 / 2 / 3 / 4 / 5, 클럽 부지 3 / 4 / 4 / 5 / 6칸 |
| 훈련 시설 Lv1\~10 | 훈련장 Lv \= 현재 ÷ 2 올림, 최대 4 |
| 메디컬 Lv1\~10 | 메디컬센터 같은 방식 |
| 스카우팅 시설 Lv1\~10 | 스카우팅 시설 같은 방식 |
| 키우미집 Lv4(전용 보유) | 키우미집 Lv2, 그 아래는 미보유 |
| 명성 60 이상 / 75 이상 | 프렌들리숍 Lv1 / Lv2 |
| 파티의 주 타입 | 훈련장 전문 타입(Lv5에서 특화 훈련이 열림) |

부지가 모자라면 훈련장, 메디컬센터, 스카우팅, 키우미집, 프렌들리숍 순으로 채운다. Lv5는 누구도 갖고 시작하지 않는다.

관장 예외: 관장 대부분은 현재 훈련 시설이 9\~10이라 훈련장·메디컬센터가 Lv4로 나온다. 그중 36개 관장 클럽은 클럽하우스가 Lv1\~2라서 클럽 건물 상한(Lv2\~3)을 넘는다. 원작 관장의 정체성이므로 그대로 두고, 클럽하우스를 올리기 전까지는 더 올릴 수 없게 한다. 같은 방식으로, 명성이 높아 클럽하우스가 도시 상한을 넘는 10개 클럽(예: 태초마을의 레드)도 그대로 시작한다. 이 예외는 시작 상태에만 적용된다.

### **경기장**

| 형태 | 시작 경기장 |
| :---- | :---- |
| 리그 | 메인 스타디움 Lv5 \+ 사이드 스타디움 Lv3, 리그 관리위원회 소유. 주민 클럽의 기존 경기장은 여기에 흡수된다. |
| 밀란형 | 주민 중 가장 높은 경기장 단계로 공동 소유 1곳. 유지비는 명성 비율로 나눈다. |
| 런던형·단독 | 클럽마다 현재 경기장 단계를 그대로(Lv1 2,000석 \~ Lv4 12,000석). 현재 경기장이 없는 클럽은 시 소유 임대 경기장(1,000석)을 쓴다. |

### **리그 관리위원회**

지방마다 리그 관리위원회가 1개 있다. 수도를 운영하고 지방 리그 전체를 관리하는 기구로, 수도가 지방의 중심처럼 느껴지게 하는 장치다.

| 항목 | 내용 |
| :---- | :---- |
| 구성 | 위원장 1(NPC 리그 사무총장) \+ 수도에 연고를 둔 클럽 5석 \+ 관장 대표 2석(직전 시즌 리그 순위가 가장 높은 수도 밖 클럽 2곳, 매 시즌 교체) |
| 의결 | 분기 1회 정기 총회, 과반 찬성으로 통과, 동수면 위원장이 결정. 긴급 안건(스타디움 사고, 재정 위기)만 수시 개최 |
| 권한 | 수도 공공 건물 건설·업그레이드, 메인·사이드 스타디움 운영과 업그레이드, 리그 일정과 대회 개최 지방 배정, 수도 전용 시설 운영, 중계권 수익 분배 |
| 예산 | 위원회 예산 \= 중계권·리그 스폰서 수익 \+ 수도 경기장 입장 수입 일부 \+ 지방 모든 클럽의 리그 분담금(명성 비례). 수도는 일반 도시의 공공예산 대신 이 예산을 쓴다 |
| 플레이어 | 수도 클럽이면 처음부터 위원이다. 수도 밖 클럽은 그중 리그 순위가 가장 높은 2곳 안에 들면 다음 시즌 관장 대표석을 얻는다. 위원이 아니어도 안건을 청원할 수 있고, 통과 여부는 위원들의 성향과 관계도로 정해진다 |

수도의 클럽 부지와 클럽 건물은 일반 도시처럼 각 클럽이 소유한다. 위원회는 공공 부지와 수도 전용 시설만 다룬다. 협의 시스템의 성향·관계도·설득 방식은 그대로 쓰고, 회의 단위만 도시 회의에서 위원회 총회로 바뀐다.

### **수도 전용 시설**

부지를 쓰지 않는 고정 랜드마크이고, 효과가 수도가 아니라 지방 전체에 미친다. 수도에 투자하면 지방의 모든 클럽이 혜택을 본다.

| 시설 | 시작 단계 | 지방 전체 효과 |
| :---- | :---- | :---- |
| 리그 본부 | Lv3 | 위원회 회의장. 단계가 오를수록 위원회 예산 수입과 안건 수가 늘어난다 |
| 메인·사이드 스타디움 | Lv5 / Lv3 | 대회 결승과 리그 경기. 사이드 스타디움 업그레이드가 위원회의 첫 장기 안건이 된다 |
| 지방 교통 허브 | Lv2 | 허브 2단계마다 수도로 가는 이동일수 1일 단축(최소 당일), 국제 대회 출전 길이 쉬워짐 |
| 방송 센터 | Lv2 | 지방 모든 클럽의 중계 수익과 명성 증가 |
| 명예의 전당 | Lv1 | 지방 소속 트레이너의 은퇴 포켓몬 기록, 명성 보너스, 관광 수입 |

시작 단계를 최고치로 두지 않아서, 위원회가 어느 시설에 먼저 투자할지가 매 시즌 정치 안건이 된다.

### **공공 건물 기본 세트**

| 크기 | 기본 건물 |
| :---- | :---- |
| 1 마을 | 주거지구 1, 상점가 1 |
| 2 소도시 | 주거지구 2, 상점가 1, 교통 1 |
| 3 중도시 | 주거지구 2, 상점가 2, 교통 2, 치안·방재 1 |
| 5 수도(리그 도시) | 주거지구 4, 상점가 4, 교통 5, 호텔·관광 3, 방송국 3, 치안·방재 3 |

여기에 두 가지를 더한다. 원작 랜드마크(★)는 원작에서 그 도시를 상징하는 시설이다(예: 태초마을 연구소, 금빛시티 라디오타워 → 방송국, 담청시티 항구 → 교통). 이미 있는 건물이면 1단계 올리고, 없으면 새로 짓는다. 타입 지구는 리그 도시를 빼고, 그 도시에서 가장 강한 관장·사천왕급 클럽의 주 타입으로 1단계를 준다. 빈 부지가 1칸 미만이 되면 타입 지구보다 랜드마크를 우선한다.

### **결과 요약**

100개 도시 중 1단계 마을 29곳, 2단계 소도시 43곳, 3단계 중도시 19곳, 5단계 수도 9곳이다. 4단계 대도시는 비워 두어 일반 도시의 성장 목표로 남긴다. 클럽 표기는 이름 하우스단계 · 건물 단계 · 주 타입이고, 건물은 훈(훈련장), 메(메디컬센터), 스(스카우팅), 키(키우미집), 숍(프렌들리숍)으로 줄였다. 공공 건물의 ★는 원작 랜드마크다.

### **남은 확인**

* 경계에 걸린 도시(점수 50\~60, 75\~85)는 원작 느낌과 맞는지 한 번 더 본다. 예: 회색시티는 관장이 약해 1단계로 시작한다.  
* 랜드마크 30곳은 원작 기억에 기반한 초안이라 도시명 확정 때 같이 검토한다. 트레이너 스쿨은 건물 목록에서 빠졌으므로 금탄도시는 연구소(데봉), 사라시티는 박물관(마스터 타워), 테이블시티는 상점가로 바꿨고 진청시티는 랜드마크 없이 시작한다.  
* 공공 예산의 시작 금액은 재정 수치를 정할 때 함께 정한다.  
* 이 표는 시작 상태일 뿐이고 AI 도시 성장 규칙은 헤드리스 시뮬로 맞춘다.
